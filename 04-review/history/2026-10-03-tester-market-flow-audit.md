# 2026-10-03 — 커뮤니티 테스터 마켓 플로우 감사 (오픈 전)

> 대상: ADR-0012 유료 시트 흐름 전 구간. 방법: 독립 감사 4개(구매자 여정 / 테스터 여정 / 돈·상태머신·크론 / 어뷰징·정책) + 코드 리뷰 2회.
> 표기: ✅ 구현으로 해소 · 🔧 운영 절차로 대응 · 👤 사용자(대표) 액션 필요 · ⏳ 수용 후 관찰

## 0. 흐름 한 장

```
구매자: 유의사항 5항 동의 → 결제(토스|크레딧) → 급구 노출+전원 알림 → [충원 기간 7일]
테스터: 규칙 동의 → 시트 참여(앱당 1회, 동시 3개) → 매일 스샷 체크인(중복 이미지 거부, 한 줄 피드백)
        → 12/14일 완주 → 보상 보류
구매자: [확정] | [이의(분류+사유)] | 3일 무응답 → 자동 확정 → 테스터 크레딧 적립
정산:   완주한 시트만 과금. 미충원·마감 후 이탈·이의 인용 시트는 환불.
```

## 2. 오픈 전 체크리스트 (사용자)

1. Resend 도메인 검증 (리마인더·영수증·확정 요청 메일)
2. 토스 전자결제 심사 → 라이브 키
3. 푸터·약관에 대표자명·사업장 주소·전화, 통신판매업 신고
4. 정책 3종(크레딧·약관 §7·환불 §2) 최종 확인
5. 본 도메인 E2E: 시트 열기 → 부계정 참여 → 스샷 체크인 → 콘솔 확인 → (DB 로 완주 시뮬) → 확정/이의 → 교환

## 3. 운영 런북 (요약)

- **매일 08:30 메일**: 제목에 [ACTION] 이 있으면 본문 항목 처리. 메일이 09:30까지 없으면 GitHub Actions → Cron Jobs 확인.
- **토스 환불**: /admin/paid-orders 의 "환불 대기 N원" → 토스 대시보드 부분취소 → [환불 완료].
- **이의**: /admin/seat-rewards → 콘솔에서 스크린샷 확인 → [지급] 또는 [몰수](구매자 시트 환불 자동). 7일 넘기면 자동 지급.
- **기프티콘**: /admin/redemptions → 문자 발송 → [발송 완료](발송 내역 필수). 영업일 3일.
- **긴급 중단**: 주문별 [시트 마감]. 전체 중단은 `PAID_TESTERS_PUBLIC_ORDERING=false` 배포.

### 독립 리뷰 2차 (MEDIUM 9 · LOW 7, CRITICAL/HIGH 없음) — 전부 반영

| # | 문제 | 조치 |
|---|---|---|
| V-1 | 7일 마감 환급 직후 관리자 [취소] → 크레딧 이중 환급 | ✅ 전액 환불은 기존 환급을 뺀 나머지만. 커뮤니티 주문 취소는 `seats_closed=false` 조건부 — 마감과 동시 실행 시 하나만 성립 |

| V-3 | 마감 후 이탈 시트 환불 실패가 "환급됨" 알림과 종결 메모에 묻힘 | ✅ 실패 시 "운영팀 확인 후 처리"로 안내, `환불 실패` 메모는 종결 때 보존·누적, 크레딧 주문도 대사 |

| V-5 | 보상 되돌리기(revert) 결과 미확인 | ✅ 미결제 크레딧 주문은 **환급 먼저 → 취소** 순서로 바꿔 되돌리기 제거. 나머지 되돌리기는 오류 확인 + 메모 |
| V-6 | 스크린샷 없는 체크인 행이 완주로 집계돼 보상 없는 완주 발생, 보류 보정 굶주림 | ✅ 유료 시트 출석 = 스크린샷 있는 날만(체크인·페널티 스윕·완주 처리 동일 기준), 끊긴 체크인은 같은 날 재시도로 이어 붙임, 보정은 증빙 일괄 조회 후 대상만 처리 |
