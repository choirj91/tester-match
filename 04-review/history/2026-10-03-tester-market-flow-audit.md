# 2026-10-03 — 커뮤니티 테스터 마켓 플로우 감사 (오픈 전)

> 대상: ADR-0012 유료 시트 흐름 전 구간. 방법: 독립 감사 4개(구매자 여정 / 테스터 여정 / 돈·상태머신·크론 / 어뷰징·정책) + 코드 리뷰 2회.
> 표기: ✅ 구현으로 해소 · 🔧 운영 절차로 대응 · 👤 사용자(대표) 액션 필요 · ⏳ 수용 후 관찰

## 0. 흐름 한 장

```
구매자: 유의사항 5항 동의 → 결제(토스|크레딧) → 급구 노출+전원 알림 → [충원 기간 7일]
테스터: 규칙 동의 → 시트 참여(앱당 1회, 동시 3개) → 매일 스샷 체크인(중복 이미지 거부, 한 줄 피드백)
        → 12/14일 완주 → 보상 보류
구매자: [확정] | [이의(분류+사유)] | 3일 무응답 → 자동 확정 → 테스터 크레딧 적립
정산:   완주한 시트만 과금. 미충원·마감 후 이탈·이의 인용 시트는 환불.
```

## 1. 발견과 조치

### 구매자 여정
| # | 문제 | 조치 |
|---|---|---|
| B-1 | 7일 미충원 환불이 문구뿐, 추적·집행 코드 없음. 첫 참여 후엔 취소·환불 전이 불가 | ✅ 일일 스윕이 결제 7일에 빈 시트 자동 마감·환불. 관리자 [시트 마감]·[환불 완료] 추가. 리포트 메일에 [ACTION] |
| B-2 | 테스터 이탈·교체가 구매자에게 안 보임 | ✅ 이탈 시 구매자 알림(재오픈/환불), 콘솔에 충원 n/N·완주·충원 마감일 |
| B-3 | 메일 전부 미발송 (Resend 도메인 미검증) | 👤 도메인 검증이 오픈 조건. 그 전까지 인앱 알림 + 관리자 우회 주소 |
| B-4 | 환불정책이 운영자 모델 문구, 몰수 시 구매자 처리 미정 | ✅ 정책 §1·§2 재작성, 몰수 시 시트 환불 + 양 당사자 통지 |
| S-1 | 초대 링크 없는 앱도 결제 가능 | ✅ 주문 API 에서 차단 + 유의사항 1항(그룹 등록) |
| S-2 | 비모집 앱이 주문 폼에 노출 | ✅ 모집중 앱만 표시 |
| S-3 | 크레딧 결제 재시도 이중 차감 | ✅ 60초 내 동일 주문 차단 (+원장 락) |
| S-4 | 급구 14일 만료 vs 시트 오픈 지속 | ✅ 열린 시트가 있으면 급구 유지(만료 스윕 예외 + 일일 재연장) |
| S-6 | 콘솔 날짜 열이 테스터별 일차와 불일치 | ✅ 열을 "각 테스터의 n일차"로 |
| S-7 | 주문이 영구 진행 중 | ✅ `settleOrderIfDone` — 진행 중 없음 + (전원 완주 | 마감) 이면 종결 |
| S-8 | "검증된", "봇 없음" 과장 문구 | ✅ 문구 완화 ("금지 — 적발 시 몰수·환불") |
| S-9 | 토스 승인 후 DB 실패 → 24h 뒤 자동 취소 | ✅ 스윕이 취소 전 토스 조회로 복구. ALREADY_PROCESSED 는 주문·금액·키 대조 |

## 2. 오픈 전 체크리스트 (사용자)

1. Resend 도메인 검증 (리마인더·영수증·확정 요청 메일)
2. 토스 전자결제 심사 → 라이브 키
3. 푸터·약관에 대표자명·사업장 주소·전화, 통신판매업 신고
4. 정책 3종(크레딧·약관 §7·환불 §2) 최종 확인
5. 본 도메인 E2E: 시트 열기 → 부계정 참여 → 스샷 체크인 → 콘솔 확인 → (DB 로 완주 시뮬) → 확정/이의 → 교환

## 3. 운영 런북 (요약)

- **매일 08:30 메일**: 제목에 [ACTION] 이 있으면 본문 항목 처리. 메일이 09:30까지 없으면 GitHub Actions → Cron Jobs 확인.
- **토스 환불**: /admin/paid-orders 의 "환불 대기 N원" → 토스 대시보드 부분취소 → [환불 완료].
- **이의**: /admin/seat-rewards → 콘솔에서 스크린샷 확인 → [지급] 또는 [몰수](구매자 시트 환불 자동). 7일 넘기면 자동 지급.
- **기프티콘**: /admin/redemptions → 문자 발송 → [발송 완료](발송 내역 필수). 영업일 3일.
- **긴급 중단**: 주문별 [시트 마감]. 전체 중단은 `PAID_TESTERS_PUBLIC_ORDERING=false` 배포.

## 4. 2차 반영 (2026-10-03 밤) — 마일스톤·적립원 단일화·리뷰 잔여
