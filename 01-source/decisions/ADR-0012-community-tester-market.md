# ADR-0012: 커뮤니티 테스터 마켓 — 유료 시트 + 크레딧 보상 (ADR-0003 분배 개정)

- **상태**: Accepted (2026-10-03)
- **결정자**: nakjun
- **관련**: ADR-0003 (크레딧 모델 — 분배 비율 개정), ADR-0007 (결제 v2 이연 — 크레딧 사용처 활성), ADR-0010 (신뢰도), ADR-0011 (운영자 테스터 — 보조 수단으로 강등)
- **개정 범위**: ADR-0003의 "테스터 800 / 플랫폼 200" → **유료 시트 완주 보상 700 (50원/일 × 14일)**. ADR-0011의 "운영팀 테스터 직접 수행"은 시트 미충원 시 폴백으로만 유지.

---

## Context

- 운영자 테스터 모델(ADR-0011)의 한계: 실기기 1대, 노동 상한, 에뮬레이터는 Play Console 기기 통계에 노출되어 고객 승급 거절 위험.
- 실데이터 (2026-10-03): 매칭 완주 **5건** vs 무단 이탈 페널티 **1,815건** (완주율 0.3%). 품앗이 호혜만으로는 14일 유지가 안 됨. 리마인더 메일은 프로덕션 발송 키 부재로 지금까지 0통.
- 인프라는 이미 존재: credits_ledger, 완주 시 적립 코드, 급구(boost) 노출, 전 회원 알림, 테스트 콘솔(슬롯×14일·스크린샷 버킷).
- 레거시 적립 크레딧 부채 4,800원 (2명) — 전액 인정 가능한 규모.

### 후보

| 안 | 내용 | 판단 |
|---|---|---|
| A. 운영자 테스터 유지 | 실기기 N대 + ADB 러너 | 기기·노동 상한, 확장 불가 |
| B. **커뮤니티 마켓 + 크레딧(폐쇄형) + 기프티콘 교환** | 구매자 1,000원/명 → 커뮤니티 테스터 수락 → 완주 시 700 크레딧 → 시트 구매 또는 임계치 기프티콘 교환 | 채택 |
| C. 커뮤니티 마켓 + 현금 지급 | 완주 시 계좌이체 | 전자금융(선불·중개)·원천징수·송금비 500원 > 보상. 2단계 재검토 |

## Decision

**B 채택.**

### 상품·분배
- 구매자: 1명 = 1,000원 (ADR-0003 단가 유지), 1~10명. 결제 = 토스 또는 보유 크레딧(1,000 크레딧 = 1시트).
- 테스터 보상: **50원/일 × 14일 = 700 크레딧, 완주 시 일괄 적립** (중도 이탈 시 0). 일별 적립 예정액은 UI 표시만.
- 플랫폼: 1,000 − PG 수수료(~3.3%) − 700 = **약 267원/명**.
- 품앗이(무료) 매칭 완주는 **크레딧 적립 없음** (신뢰도 +1/일은 유지). 기존 적립 4,800원은 시트 구매에 사용 가능(기프티콘 교환은 불가).

### 유료 시트 흐름
1. 결제 확정 → 앱에 유료 시트 N 부여, 급구 노출(14일), 전 회원 알림, 오픈채팅 공지 텍스트 생성.
2. 테스터 수락 = 기존 매칭 옵트인. 유료 시트부터 우선 배정(`matches.paid_order_id`), 시트 소진 후 무료 정원.
3. 유료 시트 테스터는 **매일 체크인 + 스크린샷 1장** 필수 (콘솔 슬롯·로그 재사용 → 구매자가 콘솔에서 증빙 열람).
4. 14일 완주 → 700 크레딧 적립 (`credits_ledger` type=earn, ref_type=paid_seat).
5. 기프티콘 교환: 유료 시트 적립분 합계 ≥ 5,000 크레딧일 때 신청 → 관리자 수동 발송 → 완료 처리. 교환 시 해당 크레딧 차감(spend, ref_type=redemption).

### 가드레일 (ADR-0011 승계 + 추가)
1. 리뷰·별점 금지 — 참여 약관 명시, 위반 시 보상 몰수 + 신뢰도 −10.
2. 어뷰징: 완주 시 일괄 지급, 스크린샷 필수, Play 옵트인 상태 확인, 테스터당 동시 유료 시트 상한(3), 신뢰도 높은 순 우선, 관리자 랜덤 감사.
3. 크레딧은 플랫폼 내 사용 + 기프티콘 교환만. **현금 환급 없음** — 현금화는 금감원 자문 후 별도 ADR.
4. 시트 미충원: 결제 후 7일 내 미충원 시트는 전액 환불 또는 운영자 테스터 투입(폴백).

## Consequences
- 전자금융·원천징수 이슈 회피 (현금 흐름은 구매자→플랫폼 단방향). 기프티콘 매입 원가는 플랫폼 마케팅 비용으로 회계.
- 통신판매업자(판매 주체) 지위 유지 — 중개업 신고 불필요.
- Google 정책: 실사용자·실기기 참여로 방어력 최대. 인센티브 테스팅 자체는 허용 영역이나, 리뷰 유도 금지는 절대 조건.
- 정책 문서 갱신 필요: 크레딧 정책(적립 700·교환 조건·현금화 불가), 환불 정책(시트 미충원), 이용약관(리뷰 금지·몰수).
- KPI: 유료 시트 완주율(목표 ≥ 60%), 시트 충원 시간(목표 ≤ 48h), 월 주문 수.
- 재검토 트리거: 시트 완주율 < 40% → 보상·리마인더 설계 재검토 / 월 주문 50건 → 통신판매업 신고 + 현금화 ADR 착수.
