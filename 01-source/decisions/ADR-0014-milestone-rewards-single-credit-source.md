# ADR-0014: 마일스톤 보상 + 크레딧 적립원 단일화

- **상태**: Accepted (2026-10-03)
- **결정자**: nakjun
- **관련**: ADR-0012 (커뮤니티 테스터 마켓 — 본 문서가 보상액 조항을 개정), ADR-0003 (크레딧 모델), ADR-0010 (신뢰도 정책)
- **대체**: ADR-0012 Decision 의 "50원/일 × 14일", 부록 A 의 "보상액 = 50 × 출석일", `03-output/policy/ranking-rewards.md` (월간 랭킹 보상 v1 — 폐지)

## Context

- 유료 시트 보상이 "출석 하루 = 50"으로 균일해, 테스터에게 중간 목표가 없었다. 실제 데이터는 완주 5건 대 이탈 페널티 1,815건(완주율 0.3%) — 끝까지 가게 만드는 유인이 필요하다.
- 크레딧 적립 경로가 둘이었다(유료 시트, 월간 랭킹 보상). 랭킹 보상은 결제 매출과 무관한 순수 비용이고, 원장 RPC 를 우회해 별도 멱등 로직을 갖고 있었다.
- 크레딧은 기프티콘으로 교환되므로(=현금성 부채), 적립원은 매출이 뒷받침하는 경로 하나로 제한하는 편이 회계·어뷰징 모두 단순하다.

## Decision

1. **크레딧은 유료 테스터 시트 참여로만 적립된다.** 월간 랭킹 보상은 폐지한다(코드·크론·관리자 화면·공개 배너 제거). 품앗이(무료) 완주와 활동 랭킹은 신뢰도 ★ 로만 보상한다.
2. **보상은 마일스톤 합계**다 (시트당 최대 700, 단일 소스 `lib/seat-reward-rules.ts`).

   | 항목 | 크레딧 | 조건 |
   |---|---|---|
   | 설치 인증 | 100 | 첫 스크린샷 체크인 |
   | 출석 | 20 / 일 | 스크린샷 체크인 1일당 (14일 최대 280) |
   | 7일 연속 | +50 | 연속 7일 출석, 시트당 1회 |
   | 완주 | +120 | 14일 중 12일 이상 출석 |
   | 개근 | +50 | 14일 모두 출석 |
   | 앱 정식 출시 | +100 | 앱 등록자가 "출시 완료" 처리 |

   - 12일 출석(7연속 포함) = 510, 14일 개근 = 600, 출시까지 = 700.
3. **지급 시점은 그대로 에스크로**다 (ADR-0012 부록 A). 설치~개근 항목은 완주한 시트에 한해 합산·보류되고, 구매자 확정 또는 3일 무응답 자동 확정으로 적립된다. 결석 3일·중도 이탈이면 0.
4. **출시 보너스**는 보상이 확정(released)된 시트에 한해, 앱이 출시 완료가 된 뒤 6시간 크론이 지급한다 (시트당 1회, 원장 부분 unique 로 멱등).
5. **시트 상한은 1~30명으로 확정**한다 (2026-10-04 사용자 결정) — 같은 날 100명 상향(`…000007`)을 적용했으나, 토스 가맹점 신청서 기재(30명)와 맞추기 위해 30으로 되돌렸고(`20261003000021`) 그대로 유지한다. 바꾸려면 상수 `PAID_TESTER_MAX_COUNT` + CHECK 제약 2개.

## Why

- 설치 인증에 큰 보상을 걸면 "참여만 하고 설치 안 함"(3일차 무체크인 해제)이 줄고, 7연속·완주·개근이 2주의 고비마다 목표를 만든다.
- 플랫폼 몫은 시트당 1,000 − 최대 700 = 300 이상으로 ADR-0012 의 수익 구조를 유지한다 (평균 지급액은 이전의 600~700보다 낮아진다).
- 출시 보너스는 구매자가 실제로 얻은 결과(프로덕션 출시)와 테스터 보상을 묶는다. 리뷰·별점과는 무관하다 (F-RVW 보류 유지).

## Consequences

- 9월분 랭킹 보상은 수상 자격자(월간 완주 1건 이상)가 없어 지급 없이 종료했다. `ranking_rewards` 테이블은 빈 채로 남긴다.
- 과거 품앗이 완주로 적립된 레거시 크레딧(4,800)은 유지하되 기프티콘 교환 대상이 아니다 (시트 구매에만 사용).
- 크레딧 정책 제2조·약관 제7조·가이드 문구를 마일스톤 표로 교체했다 — **2026-10-04 사용자 승인**.
- 출시 보너스는 등록자가 출시 처리를 하지 않으면 지급되지 않는다. 테스터 고지 문구에 "앱 출시 시"로 명시.
