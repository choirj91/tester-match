# 08 — 창업자만 답할 수 있는 질문

> 2026-10-04 답변 반영: 전부 이전·최소 사양(C1·C2), 크레딧 $5,000 이하(B1), 도메인 메일은 Google Workspace Gmail 로 수신(D3 — Email Routing 아님).

- 작성: 2026-10-04 · 답이 오기 전에는 Azure 에 닿는 명령을 실행하지 않는다

## A. 대상 Azure — ✅ 해결 (2026-10-04)

홈페이지 이전용으로 만든 `~/.azure-knockknock-homepage/target.env` 의 테넌트·구독(MS for Startups 스폰서십)·계정을 공유하기로 함 (4개 값 입력 확인, 값은 열람·기록하지 않음). A5(회사 테넌트와 별개인지)만 확인 부탁.
